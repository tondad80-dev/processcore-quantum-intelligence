02 / THE APPROACH

Curiosity starts it.
Evidence moves it forward.

ProcessCore connects the way I work across different subjects. A useful idea needs a clear question, something concrete to inspect and a deliberate decision about its next use.

01

Understand the question

Start with the situation, the people or the living environment. Define the result before building.

02

Make it inspectable

Build a bounded model or tool. Keep observations, source material and the result together.

03

Decide the next step

Separate a proposal, a checked result and permission to act. Let the evidence set the scope.

Shared authorship and principles. Project-specific results.

The portfolio shows a common line of thought. Technical integration and acceptance are described separately for each project.
