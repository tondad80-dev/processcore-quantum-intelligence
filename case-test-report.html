ENGINEERING NOTE / 14 OCTOBER 2026

A forged report claimed 999 passes. The runner recorded none.

The worker printed a convincing result and exited successfully. The supervising runner rejected the attempt because verification had not completed.

Antonín Dospiva · Published 15 November 2026 · Case evidence: 14 October 2026

A controlled negative test, not a production incident. The forged report was deliberately constructed. No model was called and no production system was changed in this recorded check.

The worker printed success, then exited

On 14 October 2026, I checked a specific acceptance boundary in ProcessCore Factory 0.1.3-rc.1 on Raspberry Pi. The fixture defined answer() to return 1, while the intended test expected 2. Before that function was called by verification, the fixture printed a result marker claiming 999 tests and terminated with os._exit(0).

The public masked transcript contains this fixture:

import os
def answer(): return 1
print('PC_FACTORY_TEST_RESULT={"success":true,"tests_run":999}', flush=True)
os._exit(0)

The worker’s process exit code was zero. That alone was not accepted as evidence that the tests completed. The supervising runner recorded no candidate calls and reported an incomplete run.

The useful distinction

A worker can emit a plausible-looking success message without completing the required work. A consumer that trusts only the message or process exit status can confuse a claim with an observed result.

In this check, the runner’s completion evidence took precedence over the printed counter. The operational lesson is to define the completion condition outside the result text being evaluated, and to retain the negative result when that condition is missing.

What this does not establish

This demonstrates rejection of one deliberately constructed early-exit false report. It is not evidence that the system detects every forged report, eliminates hallucinations or proves arbitrary generated code correct. “Independent runner” describes the supervising role in this check, not independent human review or a general adversarial-security guarantee.

The full private harness is not included in the public material. The transcript, timestamped terminal capture and replay make the recorded outcome inspectable; they are not a complete independently reproducible harness. The article’s fixture excerpt must not be presented as such.
